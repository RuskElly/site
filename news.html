📰 Новости

Новости сервера, сборки и модов RTN Project. Добавляй новую запись в news.json — она появится и на этом сайте, и в Minecraft через мод.

🤖 Новости для мода (JSON)

Мод в Minecraft читает файл news.json по адресу https://rtn.garden/news.json и показывает записи в игре.

📐 Формат news.json — схема для мода 
{
  "site": "rtn.garden",        // название проекта
  "updated": "2026-08-07",     // дата последнего обновления (ГГГГ-ММ-ДД)
  "items": [                   // массив новостей, свежие — в начале
    {
      "id": "2026-08-07-welcome",       // уникальный id записи
      "title": "Запущен новый сайт!",   // заголовок
      "date": "2026-08-07",             // дата (ГГГГ-ММ-ДД)
      "category": "news",               // категория: news | update | event
      "content": "Текст новости…",      // текст записи
      "link": "https://rtn.garden/news.html#2026-08-07-welcome"
    }
  ]
}

Поля id и category — опциональные. Мод может показывать title, date и content. Если мод ожидает другую структуру — скажи, подстроим формат под него.
