⚙️ Мои моды

Моды, которые RTN Project разрабатывает сам — все доступны на CurseForge. Поддерживаемая версия: Minecraft 1.21.1 (NeoForge).

NeoForge 1.21.1

RTN's Economy Library

Мод-библиотека экономики «всё в одном»: аналог Vault и XConomy со Spigot со встроенной системой Money From Mobs.

  • ⚔️ Деньги за мобов: пассивные 1®, враждебные 5®, боссы 100®
  • 🔥 Комбо-система x1 → x2 → x3
  • 📊 Топы: /baltop, /mfm top, /mfm info
  • 🔒 Шифрованное хранилище AES-256-GCM
  • 🧩 Публичный API для разработчиков (Vault-стиль)
  • 📦 Без зависимостей

RTN's PALM Auth

Система авторизации нового поколения: никаких чат-команд — только красивый GUI в стиле MMORPG.

  • 🚫 Без /login и /register — весь вход через GUI
  • 🖐️ Уникальная капча «Я человек?»
  • 🧍 Экран персонажа: 3D-модель, уровень, XP, баланс
  • 🔐 Автологин по сессионным токенам
  • 💳 Интеграция с RTN's Economy Library
⬇ CurseForge
Серверный

Random Loot Mob Drops (RLMD)

Лёгкий серверный мод: при убийстве любого существа есть шанс выпадения случайного предмета из твоей сборки.

  • 🖥️ Только сервер — клиент ничего не ставит
  • 🏷️ Умная система тегов (c:, neoforge:, create:)
  • ⚙️ Полная настройка: шанс, whitelist, blacklist
  • 🚀 Ноль лагов: лут-пул кэшируется при старте
  • 🎒 Идеально для больших сборок (Create, AE2, TACZ)
⬇ CurseForge
NeoForge 1.21.1

PocketGrove

Личные войд-измерения для каждого игрока: свой остров 17×17, магические деревья, уровни и челленджи.

  • 🏝️ Свой физический мир (ServerLevel) на каждого игрока
  • 🌳 3 Grove-дерева: защита, ресурсы, порталы
  • 📊 Система уровней и 24 челленджа
  • 👥 Роли: OWNER / TRUSTED / GUEST + баны
  • ⚙️ Погода, время, мобы и PvP — настраиваются в GUI
⬇ CurseForge
ℹ️ PALM Auth и PocketGrove используют RTN's Economy Library для отображения баланса — ставь его первым. Все моды RTN работают на NeoForge 1.21.1.
